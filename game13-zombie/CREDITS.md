**Важно для публикации.** Из-за запрета на перезаливку у Characters PSX папки `tools/src` (исходники)
и `assets/psx` нельзя выкладывать в открытый репозиторий как отдельные файлы. В составе собранной игры
(архив для Яндекс Игр, itch.io) они допустимы. Если игру соберут на GitHub Pages из открытого репозитория,
сначала решить вопрос с этими моделями.
Модели Characters PSX переконвертированы из FBX: скелет Mixamo автора, текстуры ужаты до 256 px, анимации свои.
